# Portfolio — Wawoli Justin Koné · Premium Edition

Version premium statique, prête pour GitHub Pages.

## Fichiers
- `index.html` — structure et contenu
- `style.css` — design premium responsive
- `script.js` — menu mobile, animations et année dynamique
- `assets/justin-kone-photo.webp` — photo professionnelle optimisée pour le web

## Déploiement GitHub Pages

1. Remplacer les anciens fichiers du dépôt `kwawoli.github.io` par le contenu de ce dossier.
2. Conserver le dossier `assets/` à la racine du dépôt.
3. Commit puis push sur la branche publiée par GitHub Pages.
4. Vérifier **Settings → Pages** si nécessaire.

Le portfolio n'utilise aucun framework ni étape de build.
