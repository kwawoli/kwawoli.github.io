# Portfolio — Wawoli Justin Koné

Portfolio statique prêt pour GitHub Pages.

## Fichiers
- `index.html` — structure et contenu
- `style.css` — design responsive
- `script.js` — menu mobile, animations et année dynamique

## Déploiement GitHub Pages

1. Remplace les anciens fichiers de ton dépôt `kwawoli.github.io` par ces trois fichiers.
2. Commit puis push sur la branche publiée par GitHub Pages.
3. Vérifie dans **Settings → Pages** que la source correspond bien à la branche/répertoire utilisé.
4. Ton site sera disponible sur `https://kwawoli.github.io/`.

## Personnalisation rapide

- Les coordonnées sont dans `index.html`, section `#contact`.
- Le lien LinkedIn est dans `index.html`.
- Les couleurs principales sont regroupées au début de `style.css`.
- Aucun framework ni build n'est nécessaire.
